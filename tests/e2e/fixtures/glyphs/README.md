# Test glyphs

Signed-distance-field glyph files (characters 0–255) for **Noto Sans Regular**
and **Noto Sans Bold**, taken from the OpenMapTiles font build
(<https://github.com/openmaptiles/fonts>, "Klokantech Noto Sans"). Used only by
the browser tests to render map labels without internet access. Noto Sans is
licensed under the SIL Open Font License 1.1.
